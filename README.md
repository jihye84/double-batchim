# 🖍️ 겹받침 놀이터

초등학교 1학년 국어 시간에 **겹받침 낱말**을 공부하는 전자칠판용 학습 게임입니다.
그림 장면과 문장 힌트를 보고, 자음 카드를 눌러(또는 끌어다 놓아) 글자 아래 **받침 자리**에 겹받침을 완성합니다.

- 설치 없이 `index.html` 하나로 실행됩니다. (더블클릭 → 브라우저)
- 전자칠판·노트북·태블릿·휴대폰 어떤 화면에서도 스크롤 없이 한 화면에 맞춰집니다.
- 조작부(자음 카드, 버튼)가 화면 맨 아래에 있어 키 작은 학생도 직접 터치할 수 있습니다.

## 바로 실행하기

이 저장소에서 GitHub Pages를 켜면 아래 주소로 바로 열 수 있습니다.

```
https://<깃허브아이디>.github.io/gyeopbatchim-playground/
```

(저장소 **Settings → Pages → Branch: main, / (root) → Save**)

## 기능

| 기능 | 설명 |
|---|---|
| 겹받침 8종 | ㄺ ㄼ ㅄ ㄳ ㄵ ㄾ ㄶ ㅀ — 한 회차 10문제에 8종이 모두 한 번 이상 나옵니다 |
| 난이도 순 출제 | 쉬움 → 보통 → 어려움 순서로 배열되며, 같은 받침이 연달아 나오지 않습니다 |
| 받침 자리 | 1학년 쓰기 공책의 십자 점선 칸처럼, 글자 위쪽(초성+중성)과 아래쪽(받침 두 칸)이 구분됩니다 |
| 입력 | 자음 카드를 누르면 빈 받침 자리에 순서대로 들어가고, 끌어다 원하는 칸에 놓을 수도 있습니다 (마우스·터치·펜 공통) |
| 순서 검사 | 자음 순서가 바뀌면(ㄱㄹ ↔ ㄹㄱ) 오답으로 처리합니다 |
| 정답 연출 | 위·아래로 나뉘어 있던 칸이 완성된 한 글자로 합쳐지고, 낱말을 읽어 줍니다 |
| 발음 표기 | 🔊를 누르면 소리와 함께 `[밥따]`처럼 표준 발음이 표시됩니다 |
| 힌트·교사 도구 | 2회 오답 시 첫 자음 힌트 / "정답 보기" / "건너뛰기" |
| 결과 | 정답 개수와 다시 살펴보면 좋은 겹받침 유형을 예시 낱말과 함께 보여 줍니다 |

## 낱말 32개

| 겹받침 | 낱말 |
|---|---|
| ㄺ | 닭 · 읽다 · 붉다 · 흙 · 맑다 · 밝다 · 굵다 · 늙다 |
| ㄼ | 넓다 · 밟다 · 짧다 · 여덟 · 얇다 |
| ㅄ | 값 · 없다 · 가엾다 |
| ㄳ | 몫 |
| ㄵ | 앉다 · 얹다 |
| ㄾ | 핥다 · 훑다 |
| ㄶ | 많다 · 끊다 · 괜찮다 · 귀찮다 |
| ㅀ | 싫다 · 끓다 · 잃다 · 옳다 · 뚫다 · 닳다 · 앓다 |

난이도: **쉬움** 닭 읽다 붉다 흙 맑다 넓다 밟다 짧다 여덟 값 없다 앉다 많다 싫다 · **보통** 밝다 굵다 늙다 얇다 몫 핥다 끊다 괜찮다 끓다 잃다 옳다 · **어려움** 가엾다 얹다 훑다 귀찮다 뚫다 닳다 앓다

그림 장면과 문장 힌트 전체 목록은 [`낱말목록.md`](낱말목록.md)에 있습니다.

## 낱말 바꾸기·추가하기

`index.html`을 메모장으로 열어 `allQuizData` 부분을 고치면 됩니다.

```js
{ prefix:'', target:'마', suffix:'다', answer:'ㄺ', level:1,   // 맑다
  scene:{ layout:'row', parts:['☀️','🏞️'] }, caption:'구름 한 점 없어요. 날씨가 {w}' },
```

- `target` 받침을 뺀 글자 (맑 → 마) · `answer` 정답 겹받침 · `prefix`/`suffix` 앞·뒷글자
- `level` 난이도 1(쉬움) 2(보통) 3(어려움)
- `scene.layout` `row`(나란히) / `stack`(위→아래 화살표) / `many`(여러 개) / `compare`(둘 중 하나, `pick:true`로 표시)
- `caption` 문장 힌트. `{w}` 자리에 낱말 길이만큼 ○가 들어갑니다
- 완성 글자(맑다)는 앱이 자동으로 조합합니다. 발음은 `PRONUNCIATION` 표에 `'맑다':'막따'`처럼 추가하세요.

## 참고

- 글꼴(Gaegu, Gowun Dodum)은 구글 폰트에서 불러옵니다. 인터넷이 없으면 기본 고딕체로 표시되며 기능에는 영향이 없습니다.
- 음성은 브라우저 내장 음성 합성(Web Speech API)을 사용합니다. 한국어 음성이 없는 기기에서는 소리가 나지 않을 수 있습니다.
